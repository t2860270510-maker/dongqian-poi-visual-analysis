# 嵊州老城·东前街 POI 可视化分析

这是浙江省绍兴市嵊州市“嵊州老城·东前街”及周边环境的 POI 可视化分析网页成果。

## 内容

- 交互式 POI 分析网页：`index.html`
- 可视化数据：`data/poi_visual_data.json`
- 静态图纸素材：`figures/`
- 分析说明：`visual_analysis_report.md`

## 说明

GitHub Pages 公开版默认使用内置静态分析底图，不提交高德 Key。  
本地课程工作目录中的 `serve_visual_analysis.py` 可以读取本机环境变量并启用高德在线底图。

数据为高德地图可检索 POI 样本，不等同于政府全量设施数据库。
