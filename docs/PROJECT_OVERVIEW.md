# 项目总览

## 项目定位

本项目围绕嵊州市“嵊州老城·东前街”及其周边环境，整理了一套从 POI 数据采集到城市设计图纸表达的课程研究成果。它既包含可复跑的数据处理脚本，也包含可直接用于汇报排版的静态图和可在线展示的交互地图。

## 研究对象

- 城市：浙江省绍兴市嵊州市
- 对象：嵊州老城·东前街及周边环境
- 核心中心点：`120.823632,29.587196`
- 坐标系：高德 GCJ-02
- 核心边界：手动圈定 `core_polygon`
- 圈层：`core_polygon`、`buffer_500m`、`buffer_1000m`

## 研究问题

本项目用 POI 数据回答以下城市设计问题：

1. 东前街核心区及周边的主导业态是什么？
2. 商业消费、文旅活动和本地生活服务之间是什么关系？
3. 公共服务、停车、公交、公厕等设施是否支撑街区更新？
4. 哪些节点适合表达慢行到达、街巷更新和公共空间策略？
5. 哪些空间问题可以被 POI 分布初步识别？

## 成果类型

- 数据表：原始 POI、清洗 POI、汇总统计。
- GIS 文件：`poi_cleaned.geojson`。
- 可视化 JSON：供交互地图和图表读取。
- 静态图：8 张 PNG/SVG 分析图。
- 在线网页：GitHub Pages 静态版和 Vercel 高德底图版。
- 文档：数据字典、采集方法、可视化说明、部署说明、局限说明。

## 使用场景

- 城市设计课程汇报图纸的数据底图。
- 东前街街区功能结构、活力、服务和交通分析。
- 课程答辩中解释数据来源、方法和限制。
- 后续叠加手绘策略、街巷空间、建筑界面和公共空间节点。
