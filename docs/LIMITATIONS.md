# 局限性说明

## POI 样本局限

本项目使用高德地图 Web 服务 API 获取 POI。POI 反映的是平台可检索的兴趣点样本，不等同于政府全量设施数据库，也不等同于真实经营状态、客流、人群停留或消费强度。

可能存在以下偏差：

- 部分小店、临时摊位、内部设施未被平台收录。
- 同一设施可能存在主点、子点、入口点等重复表达。
- POI 类型由平台定义，可能与城市设计中的功能分类不完全一致。
- 高德数据会随时间更新，复跑结果可能发生变化。

## 坐标局限

本项目保留高德返回坐标，坐标系为 GCJ-02。若与 WGS84、CGCS2000 或本地 CAD/GIS 底图叠合，需要进行坐标转换或配准。

GeoJSON 文件中的坐标虽然使用 GeoJSON 数组格式，但数值仍为高德 GCJ-02 坐标。

## 圈层局限

500m 和 1000m 圈层是以中心点为圆心的距离圈层，不是基于真实道路网络的步行等时圈。它适合课程阶段的周边影响范围分析，但不能直接代表真实步行可达性。

若后续需要更严谨的到达性分析，应补充：

- 道路网络数据。
- 真实入口、过街点、桥梁、阻隔边界。
- 步行网络最短路径或等时圈计算。

## 功能分类局限

`main_category` 是根据高德 typecode 和本项目研究目的派生的主功能分类。它便于统计和制图，但会简化复合型 POI 的真实功能。

例如：

- 商业综合体内的餐饮、购物、停车可能分别作为子 POI 出现。
- 公厕可能在高德类型中被归入公共设施，也可能被误归入其他类型。
- 文旅消费不一定等同于文旅景点，餐饮和购物也可能服务本地居民。

## 可视化判断局限

热力图和专题图表达的是 POI 点位密度与类型结构，不代表真实客流热度、营业时间或消费金额。城市设计判断仍需结合现场调研、街景观察、访谈和规划资料。

## 适用边界

本项目适用于城市设计课程阶段的空间分析、图纸表达和问题识别。若用于正式规划审批、设施配置评估或商业决策，应补充权威数据和现场核验。
