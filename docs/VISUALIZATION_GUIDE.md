## 8 张静态分析图

### fig01 研究范围总图

用途：说明核心 polygon、500m/1000m 圈层和 POI 样本总体分布。

建议放在分析开篇，作为“研究范围 + 数据基础”图。

### fig02 圈层业态结构图

用途：比较核心区、500m、1000m 的功能比例。

建议用于回答“东前街核心区与周边功能结构是否一致”。

### fig03 POI 分类点图

用途：按 `main_category` 着色展示功能分布。

建议叠加街巷、建筑界面或地块底图，用于识别业态集聚段。

### fig04 商业活力热力图

用途：提取餐饮、购物、休闲娱乐、住宿等消费型 POI，表达活力潜力。

建议用于街区活力判断、夜间经济潜力分析和商业节点识别。

### fig05 公共服务完整度图

用途：提取医疗、教育文化、政府公共服务、公共设施、公厕、停车等服务设施。

建议结合 100m/300m/500m 服务半径，表达服务覆盖与缺口方向。

### fig06 交通与到达性图

用途：提取停车场、停车场出入口、公交站、道路/路口等到达设施。

建议用于标注主要到达节点、换乘节点、慢行入口和街巷导向。

### fig07 旅游商业与本地生活关系图

用途：区分游客消费型 POI 与居民日常型 POI。

建议用于讨论旅游商业化与老城日常生活之间的平衡。

### fig08 问题诊断与设计策略图

用途：综合表达功能单一、服务缺口、停车压力、街巷联系不足等问题，并叠加设计策略。

建议作为分析到策略的过渡图。

## 交互地图筛选口径

网页现在包含两个独立模式：

- `POI筛选模式`：保留原有自由筛选，可以按专题、圈层和业态组合查看 POI。
- `图纸专题模式`：用高德在线底图重新表达 8 张课程图纸专题，切换时会自动更新图层、统计、图例和空间判断。

左侧控制面板包含：

- 专题模式：全部 POI、商业活力、公共服务、交通到达、旅游/本地生活。
- 圈层筛选：核心区、500m、1000m。
- 业态筛选：餐饮、购物、生活服务、停车场、公共服务、文旅景点等。
- 点图和热力图开关。

`图纸专题模式` 包含：

- `fig01 研究范围总图`
- `fig02 圈层业态结构图`
- `fig03 POI 分类点图`
- `fig04 商业活力热力图`
- `fig05 公共服务完整度图`
- `fig06 交通与到达性图`
- `fig07 旅游商业与本地生活关系图`
- `fig08 问题诊断与设计策略图`

点击 POI 可查看：

- 名称
- 主功能分类
- 高德原始类型
- 地址
- 圈层
- 到中心点距离

## 地图截图

网页右上角提供 `导出当前地图 PNG` 按钮。默认导出范围为地图画布，不包含左右控制面板。

导出内容包括：

- 高德在线底图或 GitHub Pages 静态 fallback 底图。
- 当前 POI 筛选或图纸专题图层。
- 导出标题、专题说明、样本数量、时间戳和图例。

Vercel 与本地服务在高德 Key 可用时使用高德在线底图截图；GitHub Pages 无 Key 时导出静态分析底图。

## 图纸表达建议

- 功能分类点图：用 `main_category` 着色，突出核心街区与周边差异。
- POI 热力图：用餐饮、购物、休闲娱乐、住宿表达消费和夜间活力。
- 服务半径图：用公共厕所、医疗、教育、停车、公交站做服务覆盖。
- 交通到达性图：叠加停车场、公交站、路口、入口和慢行路径。
- 旅游/本地生活对比图：游客消费型与居民日常型 POI 分层表达。
- 问题诊断图：叠合服务缺口、停车压力、街巷联系不足、商业过密区域。
- 策略叠合图：在问题诊断基础上添加慢行组织、公共空间节点、业态补足、文化展示和夜间经济策略。
